# Nieuwe website (voorbeeld)

- `voorstel.md`: opzet om fvdwpartijhandel.nl te vervangen door een site op dezelfde Supabase-database als het Salesbureau.
- `voorbeeld/index.html`: klikbaar voorbeeld (gepubliceerd als privé-artifact).
- `voorbeeld/build_data.py`: maakt `data.json` en kopieert productfoto's uit de projectbestanden naar een map naast het script.

`data.json` en de foto's staan bewust niet in deze repository: die bevatten verkoopprijzen en de repository is openbaar. Ze staan in de projectmap `website/voorbeeld/`.
